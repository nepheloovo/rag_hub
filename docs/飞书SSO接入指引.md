# 飞书 SSO 接入指引

## 一、在飞书开放平台创建应用

1. 登录 [飞书开放平台](https://open.feishu.cn) → 「开发者后台」→「创建企业自建应用」
2. 填写应用名称（如「知枢」），获取 **App ID** 与 **App Secret**（凭证与基础信息页）
3. **权限配置**：开通权限
   - `获取用户基本信息`（authen/v1/user_info 对应 `contact:user.base:readonly` 或直接使用网页应用登录能力，旧版应用默认具备）
4. **安全设置 → 重定向 URL**：填入
   ```
   http://<你的服务器域名或IP>:8080/api/auth/feishu/callback
   ```
   （必须与「设置 → SSO 配置」页展示的回调地址完全一致）
5. 发布应用版本并申请管理员审核（企业自建应用通常免审或需管理员通过）

## 二、在知枢中配置

1. 以平台管理员登录 → **设置 → SSO 配置**
2. 开启「启用飞书登录」，填入 App ID / App Secret，保存
3. 登录页「飞书登录」按钮自动启用

## 三、登录流程

```
用户点击飞书登录
  → 跳转 open.feishu.cn 授权页（用户扫码/确认）
  → 回调 /api/auth/feishu/callback?code=...&state=...
  → code 换 user_access_token → 获取用户信息（name/open_id）
  → 按 open_id 自动创建本地账号（角色默认：业务使用者）或关联已有账号
  → 签发 JWT → 跳回前端 /sso-callback → 进入工作台
```

- 首次飞书登录的成员**默认「业务使用者」角色**，由平台管理员在「设置 → 成员」中调整角色
- 已有本地账号可在数据库中将 `users.feishu_open_id` 关联到对应飞书 open_id，实现账号合并
- SSO 用户无本地密码，仅可通过飞书登录

## 四、注意事项

- 回调地址必须是飞书服务器可达的**公网/内网可达地址**（内网部署时飞书无法回调，需反向代理或公网域名）
- App Secret 仅保存在数据库，不通过接口回传明文
- 登录失败会在登录页提示具体错误（如凭证错误、账号停用）
- 企业微信 SSO 凭证可在同页保存，OAuth 回调流程将在后续版本开放
